# @chatlogix/utils

Utility functions package for ChatLogix applications.

## Functions

- formatDate
- formatCurrency
- formatPhone
- validateEmail
- validatePhone
- debounce

## Usage

```ts
import { formatCurrency, formatPhone } from '@chatlogix/utils';

const price = formatCurrency(1000, 'INR');
const phone = formatPhone('+911234567890');
```
